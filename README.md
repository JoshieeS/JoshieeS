#### 🚀 Featured project

**[drop-aj](https://github.com/JoshieeS/drop)**: browser-to-browser photo and video transfer between Android and iPhone over WebRTC. No upload, no app.
Disk-backed receiving with OPFS and Web Workers, data-channel flow control, and a live connection log that shows each step of the WebRTC handshake.
`Next.js` `TypeScript` `WebRTC` `Tailwind`
